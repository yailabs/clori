# Documentation and Information Architecture

Milestone ID: `V010.DOCS.INFORMATION.ARCHITECTURE.0`

Status source: [`ROADMAP.md`](../../ROADMAP.md). This contract does not own
live milestone state.

## Mission

Refound YVEX documentation around stable information authorities rather than
implementation chronology. Separate doctrine, implementation-independent
reference architecture, current implemented architecture, family facts,
normative contracts, operator procedures, development policy, project control,
decisions, frozen audits, migrations, releases, and historical recovery.

## Required boundaries

- one concise canonical glossary and one claim/evidence hierarchy;
- one owner for each major architecture, family, contract, operation, release,
  and project-control subject;
- compact public README and public changelog;
- family integration separated from DeepSeek, Qwen, and Gemma records;
- exact documentation ownership and frozen-audit manifests;
- complete old-to-new document migration evidence;
- link, authority, terminology, claim, family-stage, console-state, and roadmap
  validation;
- no product/runtime/protocol/command/REPL behavior change.

## Preservation

`ROADMAP.md` remains the only live macro authority. `AGENTS.md` remains the
engineering contract. Code/tests remain implementation authority. Accepted
ADRs and frozen audits retain their specialized roles. Git history retains
detailed retired chronology.

The accepted command taxonomy, private protocol v4, selected/live model
distinction, product topology, model-family evidence, readiness, and non-claims
are inputs and are not redefined by editorial migration.

## Acceptance

The boundary closes when every tracked living Markdown document has one class
and authority; every major subject has one owner; all old paths have a recorded
disposition; all links and guards pass; frozen evidence is unchanged; no claim
is promoted; and the next console milestone can consume stable contract and
architecture owners without recreating documentation semantics.
