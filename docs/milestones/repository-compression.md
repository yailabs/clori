# Repository Architecture Compression

Status: accepted implementation-boundary contract

Milestone: `V010.REPO.ARCHITECTURE.COMPRESSION.0`

Status source: [`ROADMAP.md`](../../ROADMAP.md)

This contract removes duplicate repository authority and ceremonial physical
partitions between the accepted execution-substrate refoundation and measured
GB10 optimization. Live state and dependency order belong only to
[`ROADMAP.md`](../../ROADMAP.md).

## Required boundary

[`config/source_owners.tsv`](../../config/source_owners.tsv) remains the sole
handwritten production-source membership and ownership authority. Build lists
are deterministic projections of that manifest; the root Makefile composes
products and supported validation entrypoints without maintaining another
path inventory or admitting sources through filesystem wildcards.

Every production file and non-public header is reconciled against a real
invariant, lifecycle, resource, policy, ABI, schema, failure contract, consumer
set, implementation class, reference oracle, or trust boundary. A physical
partition without one of those reasons is merged, inlined, generated,
staticized, or removed. The public C API is unchanged.

The DeepSeek model, graph, and CUDA translation units are independent family
projections and remain separate. Runtime stays family-neutral and owns no
`families/` directory. Source trust, Transformation IR, Physical Execution IR,
GGUF encoding, artifact admission, materialization, runtime state,
candidate-state promotion, sampling, protocol, and terminal rendering remain
distinct semantic boundaries even where nearby helpers are compressed.

Artifact support, runtime-binding availability, configured profile readiness,
selected-profile readiness, and live-daemon readiness are separate registry
facts. Registry inspection and startup project those dimensions consistently;
verification never compares unlike support stages.

## Acceptance evidence

A frozen audit bound to baseline `7226f74fe8b2c063f2485daa5c9f36be0be0387d`
records every governed file, include/link/build edges, counting method,
disposition, protected boundary, and before/after metric. Closure requires
measurable reductions in handwritten source declarations, production
translation units, internal headers, non-public globals, forwarding boundaries,
duplicate facts, historical targets, and root Makefile size without increasing
public headers, public declarations, semantic owners, or production behavior.

Clean and incremental builds, CUDA/no-`nvcc`, package, guard, unit, integration,
sanitizer, live target-only/DSpark, local protocol, REPL, registry, and OpenAI
evidence must preserve the accepted identities and behavior before one
controlled daemon cutover.

## Non-claims

This boundary does not change model or numerical semantics, artifact or binding
bytes, protocol v6, operator commands, physical policy, kernels, synchronization
order, context capacity, performance targets, evaluation, benchmark, release
qualification, or Hugging Face publication. Hardware-specific optimization
remains owned by `V010.RUNTIME.DEEPSEEK.GB10.OPTIMIZATION.0`.
